# Product Roadmap - desmotiva.tech

## Estratégias para escalar

### 1. Gamificação + Perfil de desenvolvedor
- **Níveis de sofrimento**: Níveis baseados em quantas frases o usuário já viu.
- **Sistema de badges**: "Sobrevivente do Legacy Code", "Mestre do Ctrl+C", etc.
- **Perfil público**: "João já sofreu com 847 bugs".
- **Objetivo**: Aumentar retenção e competição social.

### 2. Frases contextualizadas e trending
- **Tech-specific**: Frases sobre React, Python, Rust, etc.
- **Trending**: Seção com as frases mais compartilhadas da semana.
- **Votação**: Permitir que usuários votem nas melhores.
- **Objetivo**: SEO por tech stack e engajamento.

### 3. Feature "Meme Generator"
- **Cards visuais**: Transformar frases em imagens automáticas.
- **Templates**: Estilos como "programador raiz vs nutella".
- **Viralização**: Mais fácil de compartilhar no LinkedIn/Twitter.
- **Watermark**: Logo sutil do site em cada meme.

### 4. Daily Challenge
- **Frase do dia**: Uma frase fixa para todos os usuários.
- **Social**: Incentivar conversas diárias.
- **Push Notifications**: PWA para trazer usuários de volta.
- **SEO**: Conteúdo estático indexável.

### 5. API pública + bots
- **API Dev**: Gratuita para integrações.
- **Comando /desmotiva**: Bots para Slack e Discord.
- **Marketing**: Cada uso gera visibilidade orgânica e backlinks.

### 6. Conteúdo indexável
- **Páginas estáticas**: Ex: `/frases/react`, `/frases/legacy-code`.
- **Blog Content**: "Top 10 frases sobre X".
- **Objetivo**: Melhorar o SEO orgânico.

### 7. Integração com ferramentas dev
- **VSCode Extension**: Mostrar frase ao abrir o editor.
- **GitHub Action**: Comentar em PRs com frases desmotivacionais.

---

### Fase 1 (2 semanas)
- [ ] Meme generator visual + compartilhamento otimizado

- [ ] Páginas estáticas por categoria (`/frases/javascript`)

- [ ] Daily challenge

### Fase 3 (2 meses)

- [ ] Extensão VSCode
